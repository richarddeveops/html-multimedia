How to stop video/audio from playing again after it ends

By default, HTML5 <audio> & <video> do not repeat — they play once and stop. The only reason media loops is if you (or someone else) adds the loop attribute:

html
<audio src="music.mp3" controls loop></audio>   <!-- loops forever -->
<audio src="music.mp3" controls></audio>        <!-- plays once, then stops -->

So to make sure it doesn't play again after finishing:

Don't add loop — that's the main one.
Also avoid autoplay combined with loop — that combo is what makes media restart itself endlessly without the user asking.
If you want extra control (like a "play once only, disable replay button"), that needs JavaScript — e.g. listening for the ended event and disabling the controls — but plain HTML on its own already gives you "play once" behaviour as the default. For a pure-HTML assignment, the answer is simply: leave out the loop attribute.
